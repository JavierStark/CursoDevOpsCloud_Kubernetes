## 📘 Orquestación con Kubernetes (Módulo 3)

**Fecha:** Miércoles 6 de mayo  
**Duración:** 2 horas

### Descripción

En este módulo introducimos los conceptos clave de orquestación con Kubernetes: por qué necesitamos Kubernetes después de Docker Compose y cómo Kubernetes gestiona despliegues a escala. Comenzaremos con la arquitectura básica (pods, nodos, control plane) y las buenas prácticas para diseñar aplicaciones nativas en la nube. Practicaremos el uso de `kubectl` para interactuar con el clúster y escribiremos manifiestos YAML para `Deployment`, `Service` y `ConfigMap`. Veremos cómo exponer una aplicación, gestionar actualizaciones (rolling updates) y supervisar recursos básicos. Al final, discutiremos brevemente herramientas de orquestación adicionales como Helm para la gestión de paquetes en Kubernetes.

### Tecnologías

- Kubernetes
- kubectl
- kind
- YAML (manifiestos)
- Helm (introducción opcional)
